# 可选增强与来源边界

本技能以真实素材、可核对证据、增量返修与分层验收为核心。通用包不包含具体人物姓名、机器路径、个人素材或实际项目回执。

补充来源：[程序员bobo（AI版）原视频](https://www.douyin.com/video/7690181737237761315)。核验过原视频画面、烧录字幕与约22–29秒的三屏提示词；没有独立逐字听写，也没有实测作者的完整工具链。不要复述为“一键全流程已验证”。

## 可复用的8步顺序

分析素材/分镜 → 转写并粗剪 → 按剪后时间更新分镜 → 关键帧预览 → 字幕/B-roll/动效 → 声音 → 预览渲染及QA → 可编辑工程/工作台交付。

这一顺序是可选增强的骨架，不能覆盖真实证据约束。主流程不需要同时调用五项工具；按能力和已有环境选，避免转写/动画职责重复。缺少具体Skill、模型、依赖或权限就报告，不假装调用过。

## 五项工具的能力路由

- [HyperFrames](https://github.com/heygen-com/hyperframes)：作者用于分镜规划；工具本身还可制作预览和渲染。不限制其能力只到分镜。
- [Whisper](https://github.com/openai/whisper)：语音识别模型/工具，可选本地转写；不等于一个装上就有可靠字级对齐的官方Agent Skill。先核对已安装封装和时间粒度。
- [video-use](https://github.com/browser-use/video-use)：作者用于粗剪/调色；公开项目还包括字幕和叠加。其默认转写曾使用ElevenLabs Scribe，需要密钥并上传源音频；使用时重新核对当前配置、费用和数据目的地，未经授权不调用。
- [Remotion Agent Skills](https://github.com/remotion-dev/skills)：官方技能集合；字幕、React动画、合成、预览和渲染。不是保证一键出片的独立软件。
- [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)：镜头/动效和Motion Workbench增强，适合网页、卡片、截图与录屏包装；不是通用粗剪器。

这些项目URL来自后补官方资料核验，不是原视频给出的安装链接；作者实际版本/封装未确定。运行前阅读当前官方说明，不自动安装仓库代码或依赖。

## 可编辑工作台

已选用且环境支持Motion Workbench时，按其当前规范保留配置与工程，验证预览和最终渲染一致，并实际打开检查。未使用时交付真实可编辑JSON+脚本或原有编辑器工程，状态写 not used。禁止为了“符合教程”伪造工作台可用或强制付费服务。
