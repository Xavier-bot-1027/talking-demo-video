# 固定回归情境

下列为脱敏输入情境与检查任务，不是已经通过的真实素材验收。

| 情境 | 检查与正确处理 | 单独不足的检查 |
|---|---|---|
| 真实口播 + 静音录屏 | 保留原口播声画同区间，以对象/选项/前后状态配对；列出同步方法 | 有音轨、自动音频匹配 |
| 补拍带他人提示，切点靠近回答 | 选完整回答、标排除范围与风险，试听切点并听最终全片；重叠处补拍或保留待确认 | ASR未检出、尾部静音 |
| 手机旋转/VFR源 | 探测旋转和PTS，检查显示方向；生成代理时保留源映射，核查首中尾音画 | 编码成功、标称fps |
| 讲单题奖励但素材只有整轮结算 | 查原片；可用真选项定格标回看，再标省略过渡整轮，不伪造金币成功状态 | 全文件解码、页面相似 |
| 改一句字幕/一个镜头 | 不初始化工程；备份、改稳定镜头ID、重编时间、缓存失效、重导回执、链接新版 | 文件名没变、旧回执 |
| 改称呼 | 核字幕、侧栏、尾卡、录屏文字全部可见位置 | 只搜索SRT |
| 换背景/替代录屏 | 资产SHA256变化导致相关缓存重建，抽查实际导出帧 | mtime、旧缓存flag |
| 补拍提纲与实说不一致 | 以收到口述为准，整理事实另标说明，不补写“原话” | 计划脚本、ASR自动修辞 |
| 页面能开但链接失效 | 核最新播放器时长/版本/哈希，逐个链接和章节，反馈刷新及导出 | 进程启动日志、HTML存在 |

执行一例后记录输入证据、生成文件、实际做了哪些检查和没做哪些检查。不要把本表的预期当验收证据。
