# talking-demo-video

用于制作与增量返修「真实口播 + 屏幕操作」演示视频的 Agent Skill。提供选句与证据配对、人物小窗、字幕、可编辑工程、审片页和分层验收流程。

## 使用

将完整仓库下载或克隆到支持 Agent Skills 的客户端所读取的技能目录，保留 `SKILL.md`、`agents/`、`assets/`、`references/`、`scripts/` 的相对结构。具体技能目录与导入方式依客户端而定，请遵循其当前说明。仓库根目录就是技能根目录。

加载后可说：

> 使用 talking-demo-video，结合我的口播、录屏和最新反馈完成一版可审片的视频。

先阅读 [SKILL.md](SKILL.md)；脚本命令与工程结构见 [scripts-and-schema.md](references/scripts-and-schema.md)。

## 依赖与边界

- Python 3.9+，脚本使用标准库。
- 素材探测、基线渲染和抽帧需要已安装的 FFmpeg 与 ffprobe；烧录字幕需要 subtitles/libass 与可用字体。
- 不自动安装依赖、上传源媒体、调用付费转写或发布成片。
- 基线支持矩形人物窗、录屏片段或明确标注的定格回看；复杂动画和声音精修使用合适的编辑器或项目引擎。
- 技术检查不能代替语义检查、真实全片听音和用户最终审片。
